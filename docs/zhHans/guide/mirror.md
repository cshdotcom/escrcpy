# 内嵌镜像与键盘映射

内嵌镜像把手机画面直接渲染在 Escrcpy 自己的窗口里（而不是 scrcpy 的原生窗口），因此可以在画面上叠加键盘映射、窗口置顶、全屏等能力。视频由 WebCodecs 硬件解码，音频通过 Web Audio 播放。

## 打开方式

1. 在设备列表找到目标设备
2. 点击设备行右侧的「更多」（＋）按钮
3. 选择「内嵌镜像」

镜像窗口会记住上次的位置和尺寸；标题栏依次是：设备名、分辨率、帧率、声音开关、键盘映射、置顶、全屏、关闭。

## 输入

- **鼠标 / 触摸**：左键按下即触控，支持多指（指针分别映射为独立触点）
- **滚轮**：在画面上滚动；若启用了「滚动」键盘映射，则转换为双指捏合缩放
- **键盘**：物理按键映射为 Android 按键；中文、表情等字符直接以文本注入
- **Esc**：返回；剪贴板在窗口获得焦点时自动同步到设备
- **右键**：返回（编辑模式下右键用于添加映射）

## 键盘映射

点击标题栏的网格图标打开键盘映射面板，右侧面板顶部可切换三种模式：

| 模式 | 说明 |
| --- | --- |
| 映射关闭 | 不启用任何映射，仅保留普通触控 |
| 编辑模式 | 可右键画面添加映射、拖动节点、调整参数 |
| 使用模式 | 按下绑定的按键即触发对应触控 |

### 添加映射

1. 切到「编辑模式」
2. 在画面上右键 → 在该位置新增一个点击映射
3. 选中映射，点击「绑定按键」，按下键盘组合（Esc 取消）
4. 在下方选择映射类型并调整参数

支持的映射类型：

- **点击**：按键触发一次点击
- **滑动**：按键触发一次向上/下/左/右的滑动，可调距离与时长
- **连点**：按住按键按设定间隔连点
- **滚动**：鼠标滚轮转换为双指捏合缩放
- **摇杆**：WASD 四向绑定，按住方向键在半径内拖动，适合游戏虚拟摇杆
- **视角控制**：鼠标移动映射为视角滑动
- **宏**：按键运行一条已有的自动化工作流，可设置循环次数

### 方案管理

映射按「方案」保存，每台设备独立。面板左上角可新建 / 复制 / 删除方案；「导入 / 导出」使用 JSON 文件，方便在多台电脑之间迁移。

## 工作流可视化编辑器

「自动任务 → 工作流 → 新建工作流」现在是一个节点画布：

- 开始 → 各步骤 → 结束，自动连线
- 拖动节点调整位置；把节点拖到另一个节点上可插入到该顺序
- 工具栏支持缩放、适应画布、自动排列；Ctrl + 滚轮缩放，拖动空白处平移
- 右侧检查器直接编辑所选步骤（AI / 动作 / 延时）
- 快捷键：Delete 删除所选步骤，Ctrl + D 复制

## 网页版

开启网页版后，浏览器里新增「镜像」页签：选择设备 → 连接，画面通过 SSE 推送码流并由浏览器 WebCodecs 解码，支持触摸、键盘、滚轮、剪贴板与键盘映射（点击映射 + 按键绑定）。自动任务页同时展示工作流的可视化链路，可一键运行。
